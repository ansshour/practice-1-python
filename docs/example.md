## Среднее значение

Для выборки $x_1, x_2, \ldots, x_n$ среднее арифметическое определяется формулой:

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i.
$$

Для значений 2, 4 и 6 среднее равно 4.

| Наблюдение | Значение |
| --- | ---: |
| Первое | 2 |
| Второе | 4 |
| Третье | 6 |
