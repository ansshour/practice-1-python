## Среднее значение

Возьмём три наблюдения:

| Наблюдение | Значение |
| --- | ---: |
| Первое | 2 |
| Второе | 4 |
| Третье | 6 |

Среднее арифметическое — это сумма значений, делённая на их количество. Для выборки $x_1, x_2, \ldots, x_n$ оно вычисляется так:

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i.
$$

В нашем примере $(2 + 4 + 6) / 3 = 4$.
