## 1. Окружение Python

Используются Python 3.14.7 и uv 0.12.24. Команда `uv sync --locked` создаёт
виртуальное окружение `.venv` и устанавливает зависимости из `uv.lock`.
Отдельные pip и virtualenv заменены средствами uv. Версия Python записана
в `.python-version`, прямые зависимости — в `pyproject.toml`.

## 2. Каркас и строгая сборка

Генератор — MkDocs 1.6.1, тема — Material 9.7.7. Команда `uv run mkdocs serve`
запускает предпросмотр, `uv run --frozen mkdocs build --strict` создаёт `dist/`.
В конфигурации включены предупреждения о неверных ссылках и якорях;
строгий режим превращает их в ошибку сборки.

## 3. Научный контент

[Пример](example.md) содержит таблицу и математические формулы. Поиск работает
по локальному индексу на русском и английском. KaTeX, его стили и шрифты
включены в сайт, поэтому внешний CDN не нужен.

## 4. Репозиторий и GitHub Actions

Сборка запускается при push и pull request. Из `main` сайт публикуется
через `actions/upload-pages-artifact` и `actions/deploy-pages`.
После публикации проверяются HTTP 200 и контрольная строка.

В альтернативном подходе `peaceiris/actions-gh-pages` записывает HTML в ветку
`gh-pages`, а Pages публикует содержимое этой ветки. В нашем варианте готовый
сайт передаётся как артефакт: дополнительная ветка с HTML не требуется.

## 5. Helios и базовый URL

На Helios работают SSH/rsync, отдельные каталоги релизов, preview веток
и ручной откат.
`SITE_URL` содержит полный адрес с подкаталогом. Для Pages это
`https://ansshour.github.io/practice-1-python/`, для Helios —
`https://se.ifmo.ru/~s313344/`. Механизм описан в [P4](p4.md).

## 6. Исследование T3

[Сравнение](t3.md) охватывает GitVerse, SourceCraft, GitFlic и три варианта
хостинга. Выводы основаны на официальной документации; испытания на этих
CI/CD-платформах не проводились. План переноса учитывает MkDocs и uv.

## 7. Проверки, лицензии и отчёт

Проверяются строгая сборка, размещение в подкаталоге, русский поиск, формулы
без внешних CDN и доставка на Helios. Ошибки и результаты записываются
в локальные материалы отчёта. Код распространяется по MIT, тексты — по CC BY 4.0.
Отчёт, презентация и текст доклада хранятся отдельно от репозитория.

При первом запуске CI uv 0.11.19 не смог скачать Python 3.14.7:
`No interpreter found`. В его встроенном каталоге загрузок этой версии не было.
Обновление uv до 0.12.24 добавило поддержку нужного Python.
